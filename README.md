# Скажи со мной — интерактивные истории

AAC-страницы для ребёнка, который пользуется альтернативной коммуникацией. Сейчас доступны «Зайка» Агнии Барто и авторская история «Котик и мячик». На карточках используются открытые пиктограммы ARASAAC и локальные SVG, а персонажи и предметы созданы в Three.js без внешних моделей.

- **Сайт:** <https://istin.github.io/kidstalk/>
- **Репозиторий:** <https://github.com/IstiN/kidstalk>
- **Языки:** русский (`ru`), English (`en`), беларуская (`be`). Режим **«Авто»** следует языку браузера; ручной выбор сохраняется. Переводятся интерфейс, слова, подписи и язык системной озвучки.

**Лицензия:** текущая версия использует ARASAAC под CC BY-NC-SA 4.0 и предназначена для некоммерческого применения с обязательной атрибуцией. См. `public/symbols/arasaac/LICENSE.md` и `docs/aac-symbols.md`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Корень `/` открывает landing-каталог с превью историй; Three.js на нём не загружается.

- `?story=bunny` — «Зайка», 15 слов;
- `?story=cat` — «Котик и мячик», 12 слов;
- `?story=cat&lang=en` — история на английском;
- `?story=cat&print=1` — печатная A4-книжка в альбомной ориентации;
- `?story=cat&print=1&coloring=1` — контурный вариант для раскрашивания.

Кнопка **«Печатная версия»** находится в шапке истории. На каждой странице слева расположены слова с пиктограммами, справа — иллюстрация соответствующей сцены. Переключатель **«Цветная / Раскраска»** меняет оформление без перезагрузки. В печатном режиме Three.js не загружается; перед печатью можно сменить язык и открыть системный диалог печати/PDF.

## Что умеет страница

- переключает две истории и три языка, произнося слова системным голосом для выбранного языка;
- собирает слова в свободную фразу, произносит её, удаляет одно слово или очищает всё;
- озвучивает отдельную строку и всю историю с подсветкой текущей карточки;
- проигрывает связную анимацию: хозяйка медленно уходит, дождь начинается только на слове «дождём», зайка пытается спустить лапку и возвращается;
- ждёт завершения осмысленного действия перед переходом к следующему слову;
- запускает отдельные строки с правильного состояния сцены;
- позволяет нажимать предметы в Three.js-сцене: зайку, скамейку, хозяйку, тучу, дождь, котика, мячик, стул, лапку, маму и окно;
- показывает вторую историю с отдельной комнатой: мячик закатывается под стул, котик тянется лапой, а мама приходит и помогает;
- поддерживает клавиатурную навигацию по предметам сцены стрелками и Enter;
- позволяет вручную включить или остановить дождь;
- использует системный голос для `ru-RU`, `en-US` или `be-BY` и позволяет менять только скорость речи;
- сохраняет настройки голоса и звука в браузере;
- работает с клавиатуры, имеет крупные сенсорные цели и адаптивную мобильную раскладку;
- на телефоне в горизонтальной ориентации размещает карточки, фразу, сцену и управление в одном viewport без прокрутки страницы;
- использует чёткие SVG-превью из общей библиотеки иллюстраций, также поддерживает внешние HTTPS-изображения в манифесте;
- учитывает системную настройку `prefers-reduced-motion`.

Для звука используется Web Speech API (`speechSynthesis`). Доступные голоса зависят от операционной системы и браузера; лучше всего открыть страницу в Chrome, Edge или Safari. Записанные аудиофайлы и серверная обработка речи не нужны.

## Сборка

```bash
npm run previews  # обновить SVG-превью из общих иллюстраций
npm run build     # сам обновляет превью перед сборкой
npm run preview
```

Готовая статическая версия появится в `dist/`. Относительные пути ассетов позволяют размещать её в подкаталоге GitHub Pages.

## Тесты и crap4js

Требуется Node.js 20 или новее.

```bash
npm test                 # unit-тесты
npm run test:coverage    # Istanbul coverage через c8
npm run crap             # coverage + CRAP-анализ src/ (порог 8.0)
npm run quality          # crap4js + production build
```

[`crap4js`](https://github.com/IstiN/crap4js) установлен из GitHub, а не из одноимённого стороннего npm-пакета. Отчёт `coverage/coverage-final.json` обязателен: без него анализ намеренно падает.

Pre-commit hook уже хранится в репозитории. После клонирования включите его один раз:

```bash
git config core.hooksPath githooks
```

При изменениях JS/TS или `package.json` hook запускает `npm run crap` и не даёт закоммитить код при failing tests, отсутствии coverage или превышении CRAP-порога.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускает тесты, CRAP-анализ и сборку на каждый push в `main`, затем публикует `dist/` через GitHub Actions. В настройках репозитория **Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**.

## Структура

- `src/stories/` — манифесты историй, слова, символы, действия и контрольные точки;
- `src/app/StoryPlayer.js` — синхронизация речи, анимации и отмена воспроизведения;
- `src/scenes/` — лениво загружаемые Three.js-сцены «Зайки» и «Котика», актёры и `TweenManager`;
- `src/symbols/` — адаптер ARASAAC и локальных изображений;
- `src/main.js` — маршрутизация между каталогом, историей и печатной версией;
- `src/i18n.js` — языки, переводы интерфейса и локализация манифестов;
- `src/catalog.js` — landing с карточками и превью;
- `src/storyPage.js` — интерфейс истории, панель фразы и события плеера;
- `src/printPage.js`, `src/printScenes.js`, `src/printMode.js` и `src/print.css` — альбомная A4-книжка без Three.js, общие SVG-сцены, контурная раскраска и системная печать;
- `scripts/generate-previews.js` и `public/previews/` — автоматически генерируемые масштабируемые SVG-превью;
- `src/speech.js` — работа с голосами и речью;
- `src/icons.js` — локальные SVG-символы;
- `src/style.css` — оформление и адаптивность.

Подробнее:

- `docs/story-architecture.md` — контракты и порядок добавления новых историй;
- `docs/aac-symbols.md` — исследование открытых AAC-наборов, лицензии и выбранные ID;
- `public/symbols/arasaac/LICENSE.md` — атрибуция локально сохранённых пиктограмм.
