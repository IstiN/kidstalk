# Открытые AAC-символы для KidsTalk

Исследование наборов пиктограмм для интерактивных историй и возможности использовать их в приложении. Код интерфейса этот документ сам по себе не меняет.

## Короткий вывод

- Для **некоммерческого KidsTalk** основной кандидат — **ARASAAC**: большая международная коллекция, русская локаль поиска, публичный API и подходящие конкретные понятия для истории «Зайка».
- Для **коммерческого продукта без ограничения NC** проще лицензионно начать с **Mulberry Symbols** либо запросить отдельное разрешение ARASAAC. У Mulberry меньше символов и стиль больше ориентирован на взрослых.
- **PCS / Boardmaker** не является открытым набором: это коммерческие символы Tobii Dynavox.
- «Открытый доступ» не означает public domain. Нужно соблюдать атрибуцию, NC/SA и другие условия конкретной лицензии.

## ARASAAC API

Базовый адрес: `https://api.arasaac.org/v1`.

Примеры:

```text
GET /pictograms/ru/bestsearch/дождь
GET /pictograms/ru/search/дождь
GET /pictograms/ru/3123
GET /pictograms/3123?resolution=500
```

В спецификации присутствует русская локаль `ru`. Изображение можно получить по стабильному адресу:

```text
https://static.arasaac.org/pictograms/3123/3123_500.png
```

Для надёжной работы приложения выбранные изображения лучше сохранять локально вместе с метаданными и атрибуцией, а не зависеть от hotlinking во время использования ребёнком.

## Подбор символов для истории «Зайка»

Поиск выполнялся через русский `bestsearch`. Точных результатов для грамматических форм «зайка», «бросила», «слезть», «промокнуть» может не быть: это нормально. Пиктограмма обозначает понятие, а русская подпись сохраняет форму слова в стихотворении.

| Слово в истории | Найденное понятие | ID ARASAAC | Комментарий |
|---|---|---:|---|
| Зайку / зайка | заяц | `17265` | Точный поиск «зайка» результата не дал; использовать символ зайца с нашей подписью. |
| бросила | бросать, класть, оставлять | `5447` | Подходит по значению «оставлять»; перед окончательным выбором проверить визуально. |
| хозяйка | женщина | `4703` | Конкретизируем подписью «хозяйка». |
| хозяйка — альтернатива | девочка | `2484` | Если персонаж в сцене будет ребёнком. |
| под | под | `7047` | Точное понятие. |
| дождём | дождь | `3123` | Точное понятие. |
| остался | ждать | `8109` | Кандидат: зайка ждёт один. Сравнить визуально с «сидеть» `25081`. |
| со | с, со | `7064` | Есть отдельный символ предлога. |
| скамейки | скамейка | `3255` | Точное понятие. |
| слезть | спускаться | `8035` | После визуального сравнения выбран ребёнок, спускающийся со шведской стенки, со стрелкой вниз; он понятнее `2654` и `6053`. |

## Как хранить символ в манифесте истории

Чтобы набор можно было заменить без переписывания интерфейса, слово должно ссылаться на символ декларативно:

```js
{
  id: 'dozhdem',
  word: 'дождём',
  action: 'startRain',
  symbol: {
    set: 'arasaac',
    id: 3123,
    sourceWord: 'дождь',
    license: 'CC BY-NC-SA 4.0',
  },
}
```

Для составного понятия допускается несколько символов; для собственного SVG — `symbol: { set: 'local', id: 'cannot-down' }`.

Важно разделять:

1. **слово и его русскую подпись**;
2. **изображение символа**;
3. **действие сцены**;
4. **длительность и зависимости шага**;
5. **лицензионные метаданные**.

Тогда новые истории добавляются своим манифестом, а набор символов и Three.js-сцена подключаются независимо.

## Атрибуция для ARASAAC

При использовании изображений в приложении и в каталоге ресурсов разместить заметную атрибуцию, например:

> Пиктограммы: Sergio Palao / ARASAAC, Правительство Арагона. Лицензия CC BY-NC-SA 4.0. https://arasaac.org/

Если изображение или его производная изменены, указать наличие изменений и сохранить CC BY-NC-SA 4.0 для производного символа. Русские подписи рядом с неизменёнными пиктограммами следует перечислить как адаптацию текста интерфейса.

Перед коммерческим запуском повторно проверить лицензии всех фактически используемых ресурсов; наличие NC у ARASAAC/Sclera требует отдельного разрешения или замены ресурсов.

## Итог визуального отбора для интерактивной версии

Кандидаты были не только найдены через API, но и просмотрены в единой contact sheet. Выводы:

- `8035` выбран для «слезть»: ребёнок и стрелка вниз понятнее, чем женщина на лестнице `2654` и силуэт `6053`.
- `5447` передаёт именно бросание/выпускание предмета, поэтому смысл «оставила и ушла» обязательно дополняется анимацией ухода хозяйки.
- `5525` визуально похоже на выбор/сомнение, а не на «не смог»; в интерактивной версии используется локальный составной символ с зачёркнутой стрелкой.
- `4697` изображает сохнущие брюки и капли; для «зайка промок» понятнее локальный мокрый зайка, а не эта бытовая пиктограмма.
- Для «остался» используется локальный зайка на скамейке: человек на стуле `25081` и сцена ожидания `8109` хуже сохраняют главного героя.
- Абстрактные `под`, `со`, `до` оставлены из ARASAAC, но обязательно дублируются пространственной анимацией.

Фактически используемые файлы и их атрибуция перечислены в `public/symbols/arasaac/LICENSE.md`.

## Визуальный отбор для «Котика и мячика»

Для второй авторской истории отдельно просмотрены кандидаты ARASAAC: коты `2406`, `7114`, `38896`, `38968`, мяч `2269`, стул `3155`, лапа `5477`, доставать `5568`, мама `2458`, помощь `4570`, находить `24741` и местоимение `6480`.

| Карточка | Выбранный символ | Почему |
|---|---|---|
| Котик / котику | ARASAAC `2406` | Дружелюбный серый кот с открытой мордочкой; выбран среди четырёх кандидатов. |
| нашёл | ARASAAC `24741` | Ребёнок и мяч в мысли/поле внимания; дополняется появлением блёсток над мячом. |
| мячик / его | ARASAAC `2269` | Конкретный узнаваемый мяч; повтор помогает связать местоимение с предметом. |
| достать | ARASAAC `5568` | Рука достаёт красный мяч из коробки — близкая к сюжету ситуация. |
| Мама | ARASAAC `2458` | Узнаваемый семейный символ; в сцене мама-кошка выделена размером и бантиком. |
| помогла | ARASAAC `4570` | Две руки как знак поддержки; основное объяснение даёт действие мамы. |
| Покатил | локальный `roll` | Мяч и направление движения, а не абстрактный глагол. |
| под стул | локальный `underChair` | Показано именно пространственное отношение мяча и сиденья. |
| Лапкой | локальный `catPaw` | ARASAAC `5477` визуально оказался птичьей когтистой лапой и не подошёл котику. |
| не смог | локальный `cannot` | Сохранён единый знак неудачной попытки из первой истории. |

`6480` для местоимения «он/его» отклонён: мужчина со стрелкой не связывается с мячом. Вместо него повторяется символ мяча, а во время произношения подсвечивается сам предмет.
